Each problem includes a real-world narrative, clearly defined input/output formats, edge-case-aware test cases, and a clean, working solution.

---

## 📌 About This Repository

This repo documents my daily DSA practice journey. Instead of solving problems in isolation, every question here is:

- **Story-driven** — framed as a real-world scenario, similar to what appears in technical interview rounds
- **Test-case rich** — includes multiple test cases, including edge cases, to validate correctness
- **Pattern-focused** — organized by algorithmic technique, not just difficulty, to build strong pattern recognition
- **Consistently maintained** — updated regularly as new topics are covered
